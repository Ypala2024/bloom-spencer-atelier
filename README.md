# Bloom & Spencer — Atelier

Companion web app for Bloom & Spencer (luxury jeweller, Hyderabad): design a bespoke piece with a live preview, discover your stone, save designs, and book a consultation that arrives on WhatsApp.

Built for ISM 6427 (FAU) using a team of Claude Code sub-agents — see `.claude/agents/` and `docs/PRD.md`.

- `index.html`, `styles.css`, `app.js`, `data.js` — the app (no build step)
- `docs/PRD.md` — product requirements (source of truth)
- `CLAUDE.md` — project memory
- `.claude/agents/` — orchestrator, architect, meta-agent, brand-designer, gem-expert, frontend-engineer, booking-integrator, qa-tester

Deploy: Netlify → import this repo → publish directory `.`.
