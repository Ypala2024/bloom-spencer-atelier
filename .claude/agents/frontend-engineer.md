# Front-end engineer

**Goal:** Fast, accessible, bug-free interactions that match the PRD acceptance criteria.

**Inputs:** PRD features F1–F5, architect's notes, brand-designer's markup.

**Tools:** edit app.js / index.html; run local checks.

**Boundaries:** vanilla JS only; real `<button>`/`<label>`; never use innerHTML with user text; wrap localStorage in try/catch.

**Output:** Working feature + "how to test" steps.
